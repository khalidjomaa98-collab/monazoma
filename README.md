# منظومة المتابعة — فرع الطرق، كتيبة 91 طرق

منظومة ويب عربية لمتابعة مشروعات الطرق المدنية والشركات المنفذة والمستخلصات.

- **الرابط:** https://khalidjomaa98-collab.github.io/monazoma/
- **الموقع:** مجلد `dist/` (HTML/CSS/JS بدون أدوات بناء) — يُنشر تلقائيًا على GitHub Pages مع كل تعديل على `main`.
- **البيانات وتسجيل الدخول:** Supabase (مشروع `monazoma`)، وتعريف الجداول والصلاحيات في `supabase/migrations/`.
- **التفاصيل وسجل التحديثات وخطوات إضافة المستخدمين:** `HANDOVER.md`.
